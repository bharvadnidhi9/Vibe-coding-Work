## 🛠️ My Vibe Coding Workflow

I approach each project through a simple, iterative development process:

1. **Idea and Planning** — Define the problem, concept, or experience I want to build.
2. **Prompt and Prototype** — Use AI coding tools to explore solutions and create an initial implementation.
3. **Build and Refine** — Improve the interface, functionality, structure, and overall user experience.
4. **Test and Debug** — Run the project, identify issues, and refine the implementation.
5. **Understand and Learn** — Review the generated code and learn about the technologies and decisions behind it.
6. **Document and Share** — Organize the project, capture previews, and publish the work on GitHub.

The goal is not simply to build faster. It is to use AI as a development aid while continuously improving my own technical understanding and problem-solving skills.
